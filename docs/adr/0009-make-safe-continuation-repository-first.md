# Make Safe Continuation repository-first

Safe Continuation must work after the source identity exhausts its quota and must not silently move conversation content across identity or workspace boundaries. Its guaranteed artifact is therefore deterministic repository metadata plus user-reviewed decisions and next steps; transcript-assisted recovery is a separate consented flow that persists and sends only an edited, sanitized checkpoint. CodexFolio never writes its own state into the repository: the structured checkpoint is encrypted in app-local storage and, after the source process exits, the target profile launches a new installed Codex process against the unchanged working directory. Portable export is explicit. Exact thread identity and a no-restart hot-swap are not part of the guarantee.
