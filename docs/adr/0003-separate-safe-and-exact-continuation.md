# Separate safe and exact continuation

Identity Handoff will always offer a guaranteed Safe Continuation path: after the source Codex process exits, CodexFolio launches a new installed Codex process under the target profile in the same working directory with an approved repository-first checkpoint. This guarantee applies across authenticated profiles and workspaces but does not promise a live identity hot-swap or preservation of the exact thread. Exact Continuation is explicitly experimental, version-gated, recoverable, and automatically falls back to Safe Continuation. Shared Work Home exact resume and Isolated Identity Home transactional transfer are separate mechanisms; each requires Experimental Features plus risk acknowledgement and is never activated merely by selecting a storage mode.
