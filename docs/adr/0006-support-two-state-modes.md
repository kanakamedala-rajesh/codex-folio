# Support isolated and experimental shared state modes

VS CodexFolio will recommend one persistent Identity Home per Identity Profile, enabling Codex-owned authentication, concurrency, and isolation. It will also offer an explicitly experimental Shared Work Home mode for users who prioritize exact cross-identity session resume and shared configuration; that mode serializes Codex execution, changes only the authentication representation through a locked and recoverable transaction, fails closed on incompatible versions, and always retains Safe Continuation as a fallback. Sessions and other shared-home state remain Codex-owned.
