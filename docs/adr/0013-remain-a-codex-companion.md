# Remain a Codex companion

VenkataSudha CodexFolio will launch and observe the user's installed Codex application rather than recreate it. CodexFolio owns Identity Profile registration, selection of the effective Codex home and environment, process launch, read-only metadata collection, local aggregation, dashboard presentation, and optional handoff preparation. Codex owns authentication semantics, its interactive UI, threads and sessions, models, tools, repository actions, configuration interpretation, and execution lifecycle. Experimental integrations are narrow version-gated adapters with safe fallback, not a parallel Codex implementation.
